# MemLore brand assets

Canonical product brand is **MemLore** (ADR 0004). Files in this folder are the
source of truth for README, GitHub, and docs imagery.

## Assets

| File | Use |
|------|-----|
| `memlore-wordmark.png` | Lockup on transparent (RGBA): line elephant + MemLore |
| `memlore-wordmark-light.png` | Same lockup on white plate (light README headers) |
| `memlore-wordmark-dark.png` | Lockup on navy plate (dark headers) |

## Voice & color

- **Short tagline:** Shared engineering memory for humans and AI coding agents.
- **Punchy tagline:** Your code tells agents what. MemLore remembers **why** — and brings the **receipts**.
- **Pillars:** Authority · Provenance · Temporal knowledge · Verification · Context for agents
- **Signposts / book spines:** Decisions · Context · History · Evidence
- **Colors:** Navy (Mem / outlines) · Purple (Lore / accents) · Purple field for avatar

## Rules

1. Scholar elephant (glasses + book) is the primary mascot.
2. Prefer `memlore-hero-scholar.png` at the top of README.
3. Use only the MemLore brand name and marks from this folder.
4. Process new exports here (crop letterboxing, square avatars) before linking.
