# Lore

**Lore** is MemLore's name for preserved engineering knowledge: decisions,
conventions, observations, and context that help humans and agents understand
*why* the system is the way it is.

A **Lore Entry** is a governed unit of knowledge with scope, provenance,
authority factors, and temporal validity. Related terms (fact, episode,
evidence) describe knowledge-plane representations; governance metadata lives
in PostgreSQL.
